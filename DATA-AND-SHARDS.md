# Your data and your shards

The software licence (`LICENSING.md`) covers **the engine's code only**.

* **What you compile is yours.** Knowledge shards, slots, marks, mark stores and any other data you create with this software
  belong to you (or to whoever owns the underlying data). The software licence places no claim on them.
* **Sharing.** If you share shards publicly we recommend **CC BY 4.0** (credit the creator) or **CC0** (no conditions), so the
  community's knowledge can flow freely. You choose.
* **Privacy — read this before sharing.** A shard is **decodable**, not an anonymised embedding: the rings are built so their
  contents can be read back exactly, and anyone with the same codebook seed can decode them. **Sharing a shard shares its
  contents.** Never put personal, private or regulated data in a shard you intend to share.
* **Portability.** The shard layout is published separately as `SHARD-FORMAT.md` under CC BY 4.0, so any tool — not only this
  engine — can read and write compatible shards.
